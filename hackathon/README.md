# hackathon/

Source code for **Gukura**. See the [main README](../README.md) for what the app does and how to use it.

| Folder / file | Contents |
|---|---|
| `analysis/build_outputs.py` | Builds every result from the RDHS 2025 microdata (survey-weighted estimates, model, scenarios, peer districts). |
| `web/` | The web app (React + TypeScript + Vite). `web/public/data/` holds the aggregated results it displays. |
| `DOCUMENTATION.md` / `.pdf` | Full documentation: problem, data, methods, findings, impact. |
| `microdata/` | Not in the repository. Download the RDHS 2025 files here (see [`../data/README.md`](../data/README.md)). |
